# 🌌 Cosmos OS

An OS-inspired desktop environment built during a college Vibe Coding / AI workshop.

![Cosmos OS](https://vibequest-weld.vercel.app/)

## 🚀 About

Cosmos OS is a desktop-environment project designed to recreate the experience of using a modern operating system through an interactive graphical interface.

The project focuses on UI/UX, application integration, desktop interactions, and rapid AI-assisted development.

## ✨ Features

- 🖥️ Desktop environment
- 📅 Calendar
- 🌦️ Weather widget
- 📝 Quick Notes
- 🎵 Local music player
- 🧮 Calculator
- 📁 File/document interface
- 🖼️ Gallery
- 🌐 Browser
- 💻 Terminal
- ⚙️ Settings
- 🔍 Search
- 🚀 Application dock

## 🛠️ Built With

- Google Antigravity and Stitch 
- AI-assisted / Vibe Coding workflow

## 🎯 Project Goal

The goal was to explore how far a functional desktop environment could be developed through rapid prototyping and AI-assisted coding while maintaining a cohesive user experience.
